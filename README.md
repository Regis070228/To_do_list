# To-Do List（命令行版）

一个使用 Python 编写的命令行待办事项管理程序。在终端输入数字选择功能，可以添加、查看、修改、完成或删除任务，也可以按优先级或截止时间排序。任务保存在本地 `tasks.json` 文件中，关闭后再次运行仍能读取之前的数据。

## 功能

- 添加任务（名称、优先级、截止时间）
- 查看未完成任务
- 修改任务
- 完成任务（记录完成时间）
- 删除任务
- 查看已完成任务（最新完成的在前）
- 按优先级或截止时间排序
- 查看任务时提示已逾期或 24 小时内即将到期
- 每次修改后自动保存到 `tasks.json`

## 运行方法

只使用 Python 标准库，无需安装第三方库。在项目文件夹打开终端：

```bash
python main.py
```

## 项目结构

```text
main.py            # A：终端交互
task_manager.py    # B：任务添加、修改、完成、删除
task_utils.py      # C：任务筛选、排序、截止时间检查
storage.py         # D：JSON 文件读写
tasks.json         # 自动生成的任务数据文件（不入库）
```

数据格式、函数接口和分工见 [开发说明.md](开发说明.md)。
