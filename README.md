# To-do List 待办清单

一款面向 Windows 的本地个人待办清单桌面应用，使用 **Python + PyQt6** 开发。计划支持任务管理、多任务集、截止时间倒计时及 Windows 系统通知；不需要账号、服务器或云同步。

> **项目状态：开发中。** 当前仓库主要包含需求与技术文档，功能描述为**开发目标**，并不代表所有功能已经实现或已有可下载的程序。
>
> **开发路线：先完成便携版，后续再开发安装版。** 当前以 [开发说明.md](开发说明.md) 为功能、数据格式、接口与验收标准的正式约定。

## 一、计划实现的功能

### 任务管理与界面

- **新增、编辑、删除任务**：标题必填；优先级高 / 中 / 低（默认中）；备注可选；截止时间可精确到年、月、日、时、分，也可以不设置截止时间。
- **完成与撤销完成**：已完成任务单独显示，并记录实际完成时间；撤销完成后恢复为未完成。
- **三个顶部视图**：
  - `按截止时间`：启动时默认视图，仅显示未完成任务，截止时间越早越靠前，无截止时间排最后。
  - `按优先级`：仅显示未完成任务，依次按高 → 中 → 低排列。
  - `已完成`：仅显示已完成任务，按完成时间从新到旧排列。
- **卡片瀑布流**：整个列表不设外围边框，各任务卡片保留独立边框；宽度自适应、可滚动、不分页。点击任务标题或卡片即可查看和编辑详情。
- **时间与边框**：主界面日期使用 `MM-DD HH:mm`，详情显示完整年份；剩余时间动态更新。逾期或剩余不超过 24 小时为红色边框，剩余超过 24 小时且不超过 7 天为黄色边框，超过 7 天为白色边框，无截止时间及已完成任务为灰色边框。**日期和倒计时文字始终为黑色**。
- **当前版本不实现搜索**，也不预留搜索栏或搜索接口。

### 截止时间提醒

采用 **Windows 原生 Toast 系统通知**（桌面右下角通知），不另外设计 PyQt 弹窗。

- **自定义提醒**：每项任务可设置提前 `0–10080` 分钟提醒，默认提前 **60 分钟**。
- **固定提醒**：任务截止前 **30 分钟**，若仍未完成，再提醒一次。
- 两个提醒时间重合时合并为一次；已完成、没有截止时间或不属于当前活动任务集的任务不提醒。**提前 0 分钟**的到期提醒允许最多 60 秒调度容差；其余提醒不在截止后补发。
- 单任务通知显示**任务名称、截止时间和剩余时间**；同时出现多个提醒时只发送一条汇总通知（最多列出两个任务名称，不逐项显示剩余时间）。只有 Windows 自带的关闭方式，**不添加“标记完成”“查看任务”“稍后提醒”等按钮**，也不实现点击通知打开任务详情。
- 主窗口隐藏到系统托盘后仍可检查并发送提醒；程序完全退出、电脑关机时不能实时提醒。关闭全局提醒或切换到其他任务集期间错过的提醒不追补；撤销任务完成后不补发历史提醒，只保留未触发的未来时刻。通知提交后尽力去重，但异常崩溃时不能绝对保证仅发送一次。通知是否弹出、是否留在通知中心仍受 Windows 设置影响。

### 多任务集与桌面功能

- 可创建多个**独立命名的任务集**；每个任务集对应 `user_data/` 目录内的一个 JSON 文件。
- 同一时刻只使用**一个活动任务集**，切换后不合并数据；支持单个任务集导入与导出。
- 本地自动保存任务与设置；再次启动时恢复上次活动任务集。**同一便携数据目录只允许启动一个程序实例**，避免多进程覆盖任务数据。
- 系统托盘运行、开机自启（默认关闭）、全局提醒开关、关于页面。
- **修复开机自启**：移动或重命名便携版文件夹后，原开机自启路径可能失效。用户从新位置启动软件后，可在设置中修复路径，**不需要清空任务数据**。
- 不提供“还原应用”或一键清空所有数据的功能。

## 二、第一阶段：便携版（当前目标）

使用 **PyInstaller** 打包 Python 程序，将 EXE 和必要资源放入文件夹，再压缩为 **ZIP 便携包**。不使用 Inno Setup，也无需安装。

**预期发布目录（首次启动后）：**

```text
TodoList/
├── TodoList.exe
├── settings.json          # 首次运行自动创建
└── user_data/             # 首次运行自动创建
    ├── <taskset_uuid_1>.json
    ├── <taskset_uuid_2>.json
    └── ...
```

`settings.json` 和 `user_data/` 均存放在 **EXE 同级目录**，而不是 PyInstaller 临时目录。发布 ZIP 仅包含程序和必要资源，**不附带开发者的真实任务数据**。

**计划的使用方式：**

1. 在发布便携包后，下载并解压 `TodoList_Portable.zip` 到具有写入权限的文件夹。
2. 运行 `TodoList.exe`，第一次启动将创建设置文件和默认的“我的任务”任务集；即使数据文件夹已存在但没有任何任务集文件，也会创建默认任务集，**不会覆盖损坏的已有 JSON**。
3. 在设置中管理任务集、提醒及开机自启。以后移动、备份程序时，**请复制整个 `TodoList/` 文件夹**，不要只复制 EXE。
4. 如果移动后开机自启失效，请在新位置手动运行一次程序，并使用设置中的“修复开机自启”。

> **目前尚未发布可运行的 ZIP 或 EXE。** 建议不要从 ZIP 内直接运行，也不要将便携目录放在通常没有普通用户写入权限的 `Program Files` 下。

## 三、技术方案与开发分工

| 模块 | 主要技术或任务 | 负责人 |
|---|---|---|
| 界面与集成 | PyQt6、三个视图、任务卡片、设置、系统托盘 | A |
| 任务业务 | 增删改、完成/撤销、视图筛选排序 | B |
| 时间与提醒业务 | 截止时间、边框状态、双重提醒、去重 | C |
| 存储与 Windows 集成 | JSON、任务集导入导出、开机自启修复、原生 Toast 提交、PyInstaller 打包 | D |

所有数据保存在本地 JSON 文件中，不引入数据库或服务端。B、C 的业务模块尽量不依赖 PyQt 或直接操作文件，以便独立开发和集成。

完整目录规划、接口签名、`schema_version=2` 数据结构、`APP_VERSION=0.1.0` 和人工验收清单见 **[开发说明.md](开发说明.md)**。

## 四、第二阶段：安装版（后续规划）

便携版开发和验收完成后，再考虑使用 **Inno Setup** 制作 Windows 安装程序：

- 将用户数据与程序文件分离，计划使用 `%LOCALAPPDATA%\ToDoList\` 保存设置和任务集。
- 提供开始菜单快捷方式、标准卸载流程，以及后续升级安装的基础。
- 尽量复用已有 PyQt6 界面、任务逻辑和提醒逻辑，只调整数据目录配置与 Windows 系统集成。
- 便携版的无时区截止时间在不同电脑上按所在电脑的**本地时间**解释；安装版如有不同时间处理需求，届时另行设计。
- **安装版不属于当前开发阶段**，目前不实现安装器、在线升级、旧数据迁移。

## 五、暂不支持的功能

当前阶段不开发搜索、账号登录、云同步、数据库、在线更新、任务集自动合并、旧版 JSON 自动迁移或应用数据一键重置。

后续如有需要，再讨论任务集重命名/删除、周期任务、子任务、主题等扩展。
