# To-do List 待办清单

一个运行在 Windows 上的个人待办清单桌面应用，用来记录任务、安排截止时间并在到期前提醒。所有数据保存在本地，不需要账号或网络。

## 现有功能

### 任务管理

| 功能 | 说明 |
|---|---|
| 新增任务 | 标题必填；优先级高 / 中 / 低，默认中；备注可空；截止时间可选，可精确到年、月、日、时、分。 |
| 查看与编辑 | 点击任务即可查看详情，并修改标题、备注、优先级、截止时间和提醒提前时间。 |
| 删除任务 | 删除前二次确认。 |
| 完成与撤销 | 标记完成后任务进入已完成视图；撤销后重新回到未完成视图。 |
| 自动保存 | 任务发生变化后自动写入本地 JSON，重启后数据仍然保留。 |

### 视图与排序

- 按截止时间：只显示未完成任务，截止时间早的在前，逾期任务仍按原时间靠前，没有截止时间的排在最后；时间相同时优先级高的在前。
- 按优先级：只显示未完成任务，高 → 中 → 低；同级按截止时间早的在前，没有截止时间的排在最后。
- 已完成：只显示已完成任务，按完成时间从新到旧排列。
- 切换视图不会改变任务的保存顺序或任务编号。

### 时间与提醒

- 截止时间以 `MM-DD HH:mm` 显示，任务详情中显示完整的 `YYYY-MM-DD HH:mm`。
- 未完成任务显示剩余时间，例如 `2日3时15分`、`3时15分`、`15分`；逾期显示 `已逾期2时15分`，不足 1 分钟显示 `不足1分`，没有截止时间显示“未设置”。
- 截止紧迫程度用颜色提示：逾期或剩余不超过 24 小时为红色，超过 24 小时且不超过 7 天为黄色，超过 7 天为白色，没有截止时间或已完成的任务为灰色。
- 每个任务最多两次提醒：用户自定义提前时间（默认提前 60 分钟，可设置 0–10080 分钟）和固定的提前 30 分钟兜底提醒。
- 两个提醒落在同一时刻时只通知一次；已完成任务不再提醒；逾期后不补发提醒。
- 修改截止时间或提醒提前时间后按新安排重新判断，不追补已经过去的提醒时刻。
- 提供全局提醒开关，可以一次关闭所有通知。

### 任务集

- 可以创建并命名多个任务集，每个任务集单独保存为一个 JSON 文件。
- 同一时间只有一个活动任务集，切换任务集不会合并数据。
- 可以在设置中切换到以前创建的任务集。
- 支持导入一个任务集 JSON（与现有名称重复时需要重新命名）和导出当前任务集。
- 重启后自动恢复上次使用的任务集。

### 桌面功能

- 开机自启，默认关闭，可以在设置中开启。
- 关闭窗口后可以继续在系统托盘运行；托盘菜单支持重新打开程序和完全退出。
- “关于”界面显示当前应用版本。
- 首次关闭窗口时会提示托盘与退出行为，并记住用户的选择。
