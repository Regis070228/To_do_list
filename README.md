# To-do List 待办清单应用

一个使用 Python 编写的轻量级个人待办清单程序，通过控制台菜单操作，任务数据保存在本地 JSON 文件中，并可使用 PyInstaller 打包为可执行文件。

详细的开发设计、技术路线与小组分工请查看 [开发说明.md](开发说明.md)。

## 功能

| 优先级 | 功能 | 说明 |
|---|---|---|
| 必须 | 查看任务 | 显示任务编号、标题、优先级和完成状态。 |
| 必须 | 新增任务 | 输入任务标题并可设置优先级；标题不能为空。 |
| 必须 | 设置优先级 | 任务可设为“高 / 中 / 低”，并能按优先级排序。 |
| 必须 | 标记完成 | 按任务编号将任务标记为“已完成”。 |
| 必须 | 本地保存 | 启动时读取已有任务，修改后写回本地 JSON 文件。 |
| 必须 | 导入任务 | 从指定 JSON 文件读取任务，导入前需确认，避免误覆盖。 |
| 必须 | 导出任务 | 将当前任务清单导出到指定路径的 JSON 文件。 |
| 建议 | 按状态筛选 | 仅显示未完成或已完成任务。 |
| 可选扩展 | 修改、删除任务 | 修改任务标题或删除任务。 |
| 可选扩展 | 截止日期 | 为任务添加日期并按截止日期排序。 |

## 环境要求

- Python 3.8 或更高版本（使用标准库即可运行，无需额外依赖）。
- 打包为可执行文件时需要 PyInstaller。

## 使用方法

在项目根目录运行：

```bash
python main.py
```

程序启动后显示菜单：

```text
====== To-do List ======
1. 查看全部任务
2. 新增任务
3. 设置任务优先级
4. 标记任务完成
5. 按优先级排序
6. 导入任务
7. 导出任务
0. 保存并退出
请选择操作：
```

输入菜单前的数字并回车即可执行对应操作；输入 `0` 保存数据并退出程序。

## 数据保存

- 任务默认保存在用户主目录下的应用数据文件夹中，程序退出后数据不会丢失。
- 新增任务、修改优先级或标记完成后会自动保存。
- 使用“导出任务”可以把当前清单另存为指定路径的 JSON 文件。
- 使用“导入任务”可读取导出的 JSON 文件；导入前程序会提示确认，确认后替换当前清单。
- 如果数据文件不存在，程序会以空任务清单启动；如果 JSON 内容无效，程序会提示错误而不是崩溃。

任务数据的字段格式：

```json
{
    "id": "唯一编号",
    "title": "完成编程作业",
    "priority": "高",
    "status": "未完成",
    "created_at": "2026-10-14 15:00:00",
    "description": "可选的任务备注",
    "due_date": null
}
```

## 打包为可执行文件

```bash
python -m pip install pyinstaller
pyinstaller --onefile --name TodoList main.py
```

生成的可执行文件位于 `dist/` 目录。请在未打开 Python 源代码的情况下直接运行打包后的程序，检查菜单、数据保存、导入和导出是否正常。
