# To-do List 待办清单

一个运行在 Windows 上的个人待办清单桌面程序，用来记录任务、安排优先级和截止时间，并在任务到期前提醒。

## 核心功能（P0）

| 功能 | 说明 |
|---|---|
| 查看任务 | 主页面只显示未完成任务，列表显示任务标题、优先级和截止时间；未设置截止时间显示“未设置”。 |
| 新增任务 | 标题必填；优先级可选高 / 中 / 低，默认“中”；备注可空；新增时即可选择完整的年、月、日、时、分，也可以不设置截止时间。 |
| 编辑、删除 | 可以修改标题、备注、优先级和完整截止时间，也可以清除截止时间；删除前会二次确认。 |
| 完成与撤销 | 任务只有“未完成”“已完成”两种状态，可以来回切换；标记完成后任务从主页面移入已完成页面，撤销后回到主页面。 |
| 已完成页面 | 主页面提供“已完成”入口，在独立页面查看全部已完成任务，可以搜索、排序、撤销完成或删除。 |
| 双模式排序 | 可以在“按优先级”和“按截止时间”之间直接切换，默认按优先级。 |
| 本地存储 | 修改任务后自动保存，启动时自动读取；支持导入、导出 JSON；遇到文件错误不会丢失原有数据。 |
| 版本管理 | “关于”界面显示当前应用版本，任务文件同时记录数据格式版本。 |

排序规则：

- 主页面只显示未完成任务，已完成页面只显示已完成任务，两页各自排序。
- 按优先级：高 → 中 → 低；优先级相同时，设置了截止时间的任务排在前面，截止时间越早越靠前。
- 按截止时间：有截止时间的按时间从早到晚排列，没有截止时间的排在最后；时间相同时高优先级在前。
- 排序只影响显示顺序，不改变原始任务列表和任务编号。

## 体验功能（P1）

| 功能 | 说明 |
|---|---|
| 搜索 | 主页面和已完成页面都可按标题关键词筛选，支持中文部分匹配，英文不区分大小写；清空关键词后恢复完整列表。 |
| 截止时间标签 | 主页面显示 `MM-DD HH:mm`（如 `10-18 23:59`），新增和编辑时显示完整的 `YYYY-MM-DD HH:mm`。 |
| 时间颜色 | 未完成且已逾期或剩余不超过 24 小时显示红色；剩余超过 24 小时且不超过 7 天显示黄色；超过 7 天显示绿色；已完成或没有截止时间显示灰色。 |
| 到期提醒 | 通过 Windows 桌面通知提醒；可以关闭提醒，也可以选择在到期时、提前 1 小时或提前 1 天提醒。 |
| 防重复提醒 | 同一任务、同一截止时间和同一提前量只提醒一次；修改截止时间后可以按新时间再次提醒。 |
| 开机自启 | 设置中提供开关，默认关闭，仅在用户主动开启后改变 Windows 当前用户的开机启动项。 |
| 系统托盘 | 可以选择关闭窗口后继续在系统托盘运行；托盘菜单支持重新打开主窗口和完全退出。 |
| 任务统计 | 显示任务总数、未完成数、已完成数和完成率；没有任务时完成率显示 0%。 |

## 未来规划

以下功能不在当前版本范围内，会在后续版本中逐步提供：

- **在线检查与更新**：从可信的 HTTPS 发布源获取版本清单、下载地址和 SHA-256 校验值，经用户确认后下载并安装新版本。
- **数据格式迁移**：数据结构发生变化时提供逐版本迁移，升级前自动备份原文件。
- **任务分类与子任务**：为任务分组，并把大任务拆成可以逐项完成的小任务。
- **周期重复任务**：按照设定的周期自动生成重复任务。
- **主题设置**：提供界面主题与外观选项。
- **云同步与合并导入**：支持多设备同步和任务合并。
